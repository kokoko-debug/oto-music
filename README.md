# おとのしくみ

**学習画面：[おとのしくみを開く](https://kokoko-debug.github.io/oto-music/)**

無料のGitHub Pagesで公開しています。PC・iPadからアクセスでき、PCを起動しておく必要はありません。

入門からアドバンスまで、音程とコードを学ぶ個人用のWebアプリです。
基礎 → 練習 → 復習と進み、早見表や鍵盤で確かめられます。練習では「全何問中の何問目」と項目一覧で現在地を示します。説明は短く、補足は必要なときだけ開きます。

## 開発と確認

必要なもの：Python 3、Node.js。npmパッケージのインストールは不要です。

```sh
node scripts/test.cjs
python scripts/build.py
python scripts/check-build.py
python -m http.server 8766 --bind 127.0.0.1 --directory dist
```

ブラウザで `http://127.0.0.1:8766/` を開きます。編集するのは `src/` です。`dist/` は生成物です。

- `practice.js`：問題・答え合わせ・復習。
- `learning.js`：基礎・早見表・鍵盤の音程／コード判定・転回形。
- `chatgpt.js`：PC用補助拡張への質問引き渡し。
- `storage.js`：このブラウザへの保存。
- `theory.js`、`advanced.js`、`advanced.css`：綴りを含む単音程・37種類のコード構成音・反復と解き直し・コード図鑑。
- `layout.html`、`styles-*.css`：画面構成とスタイル。

ビルド後は単独のHTMLで動くため、外部ライブラリの読み込みやAPI料金は不要です。
全169組の音程・全72通りの三和音／転回形・2,300通りの3鍵選択・全216通りの三和音転回切り替え・全336通りのセブンス／転回形・1,344通りの転回切り替え・入門の問題340問・保存の復元を自動検査します。
さらに1,600通りの綴り付き単音程と、37種類×全12音のコード444通り、セブンスの転回形、厳密な音名判定、反復順とアドバンスの保存値も検査します。

## アドバンス

学習メニューの「アドバンス」から使えます。入門の進行と履歴は保持します。

- 単音程：1〜8度・半音0〜12個を反復。長・短・完全、増・減、重増・重減と二重変化記号の3段階。五線譜で出題し、上行／下行を選べます。半音数が同じでも、綴りから度数を区別します。
- コード構成音：三和音・sus、セブンス7種類、6・add、9・11・13、変化音付きの範囲を選択。Cだけ／全12音で練習。音名ボタンで構成音をすべて回答します。
- 20問／50問／無制限の反復。答え合わせ後の短い解説、正解数・連続正解、間違えた問題の解き直し。選択中の回答とセッションを保存します。
- コード図鑑：ルート（根音）と種類から構成音・度数・3オクターブの鍵盤を表示して再生。三和音とセブンスは転回形を切り替えられます。

問題では「省略なしの構成音」を回答し、順番・オクターブは問いません。異名同音の綴りは区別します。9・11・13は下位の7・9・11を含む教材上の積み重ねです。実演では5度や11度などを省くことがありますが、この問題にはその省略を適用しません。`7(#11)`など7に個別指定した音は、その指定だけを追加します。`add9`に7度は含めず、`sus`は3度を置き換えます。アプリ内の「出題ルールと参考教材」でも確認できます。

音程・セブンスの規則は[University of Puget Soundの音楽理論教材](https://musictheory.pugetsound.edu/mt21c/AugmentedAndDiminishedIntervals.html)、[Seventh Chords](https://musictheory.pugetsound.edu/mt21c/SeventhChordsIntroduction.html)で確認し、テンション・add・susは[Open Music TheoryのChord Symbols](https://viva.pressbooks.pub/openmusictheory/chapter/chord-symbols/)を参照しています。説明・問題は本アプリ用の独自作成です。

## GitHub Pagesで無料公開する

このフォルダだけをリポジトリに入れます。作業用の親フォルダ、PC用ランチャー、補助拡張、確認画像は含めません。

1. GitHubで公開用のリポジトリを作成し、このフォルダの内容をアップロードします。既定ブランチは `main` にします。
2. Settings → Pages → Build and deployment → Source を **GitHub Actions** にします。
3. Actionsの「Test and publish to GitHub Pages」を実行します。以後、mainへの更新時に検査・ビルド・公開が行われます。
4. Pagesに表示されるURLをPCとiPadで開きます。PCの起動は不要です。

GitHub FreeのPagesは公開リポジトリが対象です。アプリとソースは公開されます。学習履歴はアップロードされず、使うブラウザに保存されます。
URLにはアクセス制限がありません。独自ドメインは不要です。

公式手順：[GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages)、[Actionsでの公開](https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages)。

## 現在の範囲

- iPad：基礎、問題、復習、早見表、鍵盤、音の再生。ホーム画面への追加はSafariの共有メニューから行えます。
- PC：上記に加えて、設定済みの補助拡張でChatGPTへ質問できます。
- PCの公開URLからのChatGPT自動質問には、補助拡張0.6.1への更新が必要です。対象はこのアプリのURLと既存のPCローカルURLだけです。拡張はこのリポジトリには含めていません。
- 学習履歴は端末間で共有されません。公開URLはローカルのURLとは別の保存場所になります。
- 早見表は三和音とセブンス7種類を掲載し、4和音のルート（根音）を全12音から選べます。自由な鍵盤選択でもメジャー／マイナー三和音とセブンス7種類を判定し、第3転回形まで切り替えられます。dim7のような複数解釈はルートを選択できます。テンションはアドバンスの構成音問題とコード図鑑で扱います。
- 初版のiPad実機での操作と音の再生は、ユーザーから確認OKの報告を受けています。アドバンスの追加後の表示と操作は別途検証します。

今後は問題の種類を増やし、入門順の出題と復習を充実させます。画面の基本の操作感は引き継ぎます。


## 入門練習を広げる

- 音程：長・短・完全の2音問題84問と、音程名→半音数12問。増・減の2音問題98問と、音程名→半音数14問。Cで確認する範囲と、基準の音を変える範囲を選べます。
- コード：基本の三和音24問、増・減三和音24問、7種類のセブンス×12ルートで84問。Cだけで仕組みを確認する範囲も選べます。
- 4択から構成音を選び、短い解説・ヒント・その範囲の早見表を確認。間違えた問題は復習に残ります。長い練習は現在の問題と前後を表示し、全項目一覧は必要なときに開けます。
- 範囲を解き終えると次の範囲へ進めます。4和音と増・減音程の先は、アドバンスの記述式に近い構成音選択・重増重減・テンションへ進みます。

増減三和音の定義は [University of Puget Sound — Triads](https://musictheory.pugetsound.edu/mt21c/TriadsIntroduction.html) で照合。増減音程とセブンスは既記の教材で確認しています。問題・解説は独自作成です。
